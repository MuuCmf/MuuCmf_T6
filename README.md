# MuuCMF-T6

### 🤖 AI 撸码专属底座 | PHP + Vue3 开源业务框架

> 拒绝重复造轮子，拒绝祖传屎山。

## 📢 这玩意儿是干啥的

MuuCMF-T6 是一套拿来就能直接做互联网业务的开源开发底座。

后台直接上 **Vue3 + Pinia + Element Plus SPA 单页应用。

技术底座采用最新 ThinkPHP6 + MySQL + Redis 开发，将 CMS 和 Framework 两个概念结合，提供多应用整合开发解决方案。开发人员只需专注于业务系统的开发。

## ✨ 亮点速览

### 🤖 AI Coding 友好

- 代码带类型标注与整齐注释，大模型读代码不头疼
- 模块划分干净、低耦合，AI 可以直接生成控制器、模型、Vue 页面
- 简单流程：丢需求 → AI 写代码 → 直接部署上线
- Codx、Claude、Cursor、Kimi、Copilot 随便上，不用反复折腾提示词

### 🚀 Vue3 SPA 新版后台

- 单页无刷新，切菜单不白闪，筛选与表格状态不会莫名丢失
- 全套统一现代化 UI，不会东一个弹窗样式、西一个弹窗样式
- 表格、弹窗、搜索筛选、权限路由全部重做
- 大小显示器都适配，手感对标商业成品后台

### 🧩 开箱自带的业务能力

- RBAC 权限管理、角色菜单权限
- 公众号、小程序（微信 / 抖音 / 百度）、H5 登录授权一站式搞定
- 微信支付 V3，订单与退款逻辑已封装
- 商业应用矩阵：在线题库、云课堂、知识付费、会员、积分、分销营销等等等
- 点播课、直播、专栏、商城、线下活动、资料下载
- OSS / COS 云存储直传，文件自动清理，不用手写文件管理

### 🛠 开发者体验

- 多应用模块化，业务代码互相隔离，二开不容易搞崩底层
- 前后端分离，PHP 后端 + Vue3 前端各司其职
- 日志、缓存、安全校验、表单验证全部封装好
- 常用功能与第三方 API 大量封装，告别重复劳动
- 持续迭代更新，安全补丁及时跟进，长期维护

## 环境

- PHP >= 8.0.2
- MySQL >= 5.6 且 <= 8.0（需支持 innodb 引擎，8.0 需取消严格模式）
- Redis >= 6
- Apache 或 Nginx

## 产品介绍

Muu+ 系列应用，是基于 MuuCmf T6 开源框架开发的一款渐进式轻应用的矩阵。您可以通过自由组合应用模块，来形成独特的运营模式。支持点播课、直播、专栏、商城、线下活动、分销、题库考试、资料下载、线下课等功能。低代码 / 无代码 DIY 设计理念，让开发者用最低的成本、最快捷的搭建平台。您也可以基于 MuuCmf T6 开源框架二开新功能，可实现与 Muu+ 系列应用完全打通。
